# Cairo Metro App

**A Flutter-based Cairo Metro trip planner designed to help users explore stations, plan journeys, and navigate the metro system more easily.**

---

## 📌 About the Project

Cairo Metro App is a mobile application developed with Flutter to make using the Cairo Metro system easier and more convenient.

Users can select their departure and destination stations, view route information, explore the metro map, and access useful trip details in one place.

The application provides a simple interface and supports both Arabic and English to make the experience accessible to a wider range of users.

## 🎯 Project Objectives

- Simplify metro trip planning.
- Help users find stations and choose their journey.
- Present route details in a clear and organized way.
- Make metro information easier to access through a mobile application.
- Provide an Arabic and English user experience.

## ✨ Features

| Feature | Description |
|---|---|
| **Station Selection** | Choose departure and destination stations. |
| **Station Search** | Search for stations and select them from the station list. |
| **Trip Planning** | View route information for the selected journey. |
| **Route Details** | Display trip details such as stations, transfers, and estimated travel information when available. |
| **Fare Information** | Calculate and display the estimated metro fare. |
| **Ticket Booking Flow** | Access the application's ticket booking flow. |
| **Metro Map** | Explore the Cairo Metro map. |
| **Nearest Stations** | Use device location to find nearby metro stations, subject to location permission. |
| **Language Support** | Switch between Arabic and English. |

## 🚀 Getting Started

Follow these steps to run the project locally.

### Prerequisites

Make sure you have installed:

- Flutter SDK
- Dart SDK (included with Flutter)
- Android Studio or another supported IDE
- An Android emulator or a physical Android device

### Installation

1. Clone the repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Navigate to the project directory:

   ```bash
   cd cairo_metro_app
   ```

3. Get the project dependencies:

   ```bash
   flutter pub get
   ```

4. Run the application:

   ```bash
   flutter run
   ```
